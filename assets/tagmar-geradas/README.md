# Ilustrações geradas para o compêndio

Esta pasta contém ilustrações originais geradas para itens que não possuíam imagem própria. Elas não substituem artes existentes e permanecem versionadas localmente para que o Foundry não dependa de links externos.

## Primeiro lote

- `combate-aereo.webp`: guerreira alada executando uma manobra de combate sobre montanhas e nuvens.
- `combate-aquatico.webp`: guerreira aquática executando uma manobra de combate em ruínas submersas.

As duas imagens foram geradas em 16 de agosto de 2026 com a ferramenta integrada de geração de imagens do Codex, sem texto, marcas ou logotipos. Os originais quadrados foram reduzidos para 768 × 768 e convertidos para WebP, qualidade 88.
